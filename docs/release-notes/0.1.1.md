## MRRadar 0.1.1

* **Updates:** MRRadar now finds new versions and installs them itself, after checking the checksum, the signature and Apple's notarization. Settings → Updates has the switch. This release has to be installed by hand once; later ones arrive by themselves.
* **Settings** have a new layout with a sidebar, like Remote Code.
* **The sidebar** marks the selected app clearly, also when the window isn't in focus.
